# 🌌 Linux VR Pro (Project Pocket VR)

**The first open-source operating system optimized for standalone, pocket-sized PCVR.**

---

## 🚀 The Concept
The goal of **Linux VR Pro** is to transform an ultra-compact Mini-PC (worn on a belt or in a pocket) into a true standalone PCVR console for the **Meta Quest 3**. No more heavy gaming laptops or massive desktop towers needed to play masterpieces like *Half-Life: Alyx* or to work on giant virtual screens anywhere you go.

The pocket unit handles all the heavy lifting under Linux, creates its own ultra-fast local Wi-Fi hotspot, and streams the VR feed directly into the headset via a dedicated APK Launcher.

---

## 🛠️ Target Architecture

* **OS Base:** Arch Linux (ultra-lightweight, heavily optimized, zero bloatware).
* **XR Engine:** Monado (OpenXR) + WiVRn / ALVR for ultra-low latency streaming.
* **Target Hardware:** AMD Ryzen Mini-PC (Radeon 780M GPU) + USB-C Power Delivery External Battery (65W-100W).

---

## 🎮 Core Features

* **🎮 Gaming Mode:** Maximum hardware performance optimization (TDP tuning, RAM priority) for flawless VR gaming on the move.
* **💼 Workstation Mode:** A 360° mixed-reality desktop environment to code, write, or multi-task on giant floating screens anywhere.
